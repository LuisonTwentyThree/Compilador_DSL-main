─────────────────────────────────────────────────────────────────────────────
COMPILACIÓN Y EJECUCIÓN
─────────────────────────────────────────────────────────────────────────────

Compilar Java:
  $ javac GeneradorEnsamblador.java
  $ javac VisualizadorArboles.java
  $ javac IntegradorSalidaASM.java
  $ javac EjemploGeneracionASM.java

Ejecutar ejemplo:
  $ java EjemploGeneracionASM

Ensamblar (NASM):
  $ nasm -f elf64 salida_dsl.asm -o salida_dsl.o
  $ ld salida_dsl.o -o programa
  $ ./programa

Ensamblar (GCC):
  $ nasm -f elf64 salida_dsl.asm -o salida_dsl.o
  $ gcc -no-pie salida_dsl.o -o programa
  $ ./programa

ESTRUCTURA DEL ÁRBOL VISUAL
─────────────────────────────────────────────────────────────────────────────

   ├── [50 : Raíz] h=3
   │   ├── [30 : Izquierda] h=2
   │   │   ├── [20 : Sub-izq] h=1
   │   │   └── [40 : Sub-der-izq] h=1
   │   └── [70 : Derecha] h=1

Significado:
  ├──   Nodo con hermano a la derecha
  └──   Último nodo en esta rama
  │    Continuación vertical
  h=N  Altura del nodo

─────────────────────────────────────────────────────────────────────────────
ESTADÍSTICAS DEL ÁRBOL
─────────────────────────────────────────────────────────────────────────────

Altura:          Profundidad máxima desde raíz
Balance:         altura_izq - altura_der
                   0:   Balanceado
                  >1:   ⚠ Desbalanceado izquierda
                  <-1:  ⚠ Desbalanceado derecha

Total Nodos:     Cantidad total de nodos
Nodos Hoja:      Nodos sin hijos

─────────────────────────────────────────────────────────────────────────────
RECORRIDOS
─────────────────────────────────────────────────────────────────────────────

Preorden (Pre-order):
  Proceso: Raíz → Izquierda → Derecha
  Ej: 50 30 20 40 70
  Uso: Copiar árbol, pre-procesamiento

Inorden (In-order):
  Proceso: Izquierda → Raíz → Derecha
  Ej: 20 30 40 50 70
  Uso: Obtener valores ordenados (ABB)

Postorden (Post-order):
  Proceso: Izquierda → Derecha → Raíz
  Ej: 20 40 30 70 50
  Uso: Eliminar árbol, post-procesamiento

Por Niveles (BFS):
  Proceso: Cada nivel en orden
  Ej: Nivel 0: 50 | Nivel 1: 30 70 | Nivel 2: 20 40
  Uso: Búsqueda por amplitud, visualización

─────────────────────────────────────────────────────────────────────────────
TIPS Y TRUCOS
─────────────────────────────────────────────────────────────────────────────

• Usar inorden para verificar que el ABB está ordenado
• Usar preorden para procesar antes de recursión
• Usar postorden para eliminar el árbol
• Usar BFS para visualización nivel por nivel
• Monitorear balance para detectar degradación
• El inorden de un ABB siempre está ordenado
